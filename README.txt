# وب‌سایت معرفی استاد

این پروژه با سه فناوری ساخته شده است:

- HTML برای ساختار صفحات
- CSS برای طراحی و ظاهر
- JavaScript برای قابلیت‌های تعاملی

## فایل‌ها

- index.html: صفحه معرفی استاد
- activities.html: صفحه فعالیت‌های علمی، سخنرانی‌ها و مدارک
- css/style.css: استایل کامل سایت
- js/script.js: قابلیت منوی موبایل و بزرگ‌نمایی مدارک
- images/: محل قرار دادن عکس استاد و مدارک

## تغییر اطلاعات استاد

در فایل‌های HTML عبارت‌های نمونه مثل «دکتر محمد احمدی»، «دانشگاه نمونه» و اطلاعات فعالیت‌ها را با اطلاعات واقعی استاد جایگزین کنید.

## اضافه کردن عکس‌ها

سه فایل زیر را داخل پوشه images قرار دهید:

- professor.jpg
- certificate1.jpg
- certificate2.jpg

برای بهترین نتیجه، عکس استاد و مدارک با کیفیت مناسب استفاده کنید.
